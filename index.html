Clock generation: 555 astable

The capacitor charges through R1 + R2 up to ⅔ Vcc, then discharges through R2 down to ⅓ Vcc. The output is high while charging and low while discharging, giving a square wave.

f = 1.44 / ((R1 + 2R2) × C)

R1 = 1 kΩ, R2 = 68 kΩ, C = 10 µF gives f ≈ Hz, about one pulse per second. Real parts have tolerances, so the actual rate will differ slightly.

Top: capacitor voltage. Bottom: output. Real time, scrolling right to left.

Counter working

Units count 0–9, tens count 0–5. When seconds reach 60 a carry pulse advances the minutes.

Start / Stop / Reset logic

Two cross-coupled NAND gates form an SR latch. Each output feeds the other gate, so the latch remembers its last command after the button is released.

Start (active low) sets RUN to 1 and lets clock pulses through. Stop sets RUN to 0 and the count freezes. Reset clears the counters and the latch.
